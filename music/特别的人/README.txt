本文件夹放置"特别的人"歌曲（用于回忆场景，有歌词同步）。

规则（与代码约定一致）：
- 文件夹名 = 歌曲名，例如「特别的人」
- 音频文件名 = 文件夹名 + 扩展名，例如：特别的人.mp3
- 歌词文件名 = 文件夹名 + .lyrics.js，例如：特别的人.lyrics.js

请将你的音频文件放入此文件夹并命名为：
    music/特别的人/特别的人.mp3

支持的格式：.mp3 / .m4a / .ogg / .wav（mp3 兼容性最好）

代码从相对路径 music/特别的人/特别的人.mp3 加载，file:// 双击打开即可播放。
若没有放置音频文件，页面仍可正常运行，只是没有背景音乐。

歌词：编辑 同目录的 特别的人.lyrics.js，把 time（秒）与文本对齐你的音频。
回忆场景的卡片轮播进度、进度条、歌词都由这首音频的 currentTime 驱动。
